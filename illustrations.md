# Illustrations manifest

All images in `src/assets/illustrations/` are original, procedurally generated artwork (`npm run illustrations`, script: `scripts/generate-illustrations.mjs`). They carry the visible "Illustrative" badge and are meant to be replaced by real renders or photos. Replace by dropping a file with the same name into the folder.
